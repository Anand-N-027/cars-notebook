Car Price Prediction with Linear Regression
A notebook-based machine learning project that predicts car prices from vehicle specifications and ownership information.

The project uses regression to model Price from features such as brand, model, engine size, mileage, fuel type, transmission, and car age. It includes data inspection, exploratory visualizations, preprocessing, model training, and evaluation on a held-out test set.

Features
CSV dataset loading and preview

Missing-value inspection

One-hot encoding of categorical features

Numerical feature correlation heatmap

Pairwise visualizations grouped by fuel type

Car-age feature engineering

An 80/20 train-test split

Linear regression training

Mean squared error and R-squared evaluation

Actual-versus-predicted price visualization
